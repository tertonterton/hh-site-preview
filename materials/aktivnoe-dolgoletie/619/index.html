24.11.16. Калининградские пенсионеры стали участниками проекта «Активное долголетие»

Региональный некоммерческий благотворительный фонд местных сообществ «Калининград» включился в работу по социально значимому проекту «Активное долголетие», который реализуется Региональной общественной организацией инвалидов "Здоровье человека" (г. Москва).

В рамках проекта запланированы мероприятия, посвященные теме туризма для пожилых людей, будут подготовлены и проведены два однодневных тура для калининградских пенсионеров в г. Калининграде и Калининградской области. Всего на бесплатные экскурсии смогут попасть более 50 калининградских пенсионеров.

В ходе проекта будут разработаны вело- и пешие маршруты для пенсионеров по региону, к лету 2017 года будет выпущен путеводитель по экологическим, сельским и спортивным маршрутам, адаптированным для пожилых людей.

Первая интерактивная поездка состоится 23 ноября 2016 года. Пенсионеры из Гвардейска проедут по историческому маршруту и посетят Гусевский историко-краеведческий музей им. А.М.Иванова, совершат прогулку по памятным местам в городе Гусев и окрестностях.

В декабре состоится вторая экскурсия, уже для калининградских представителей «серебряного возраста», в ходе которой они ознакомятся с достопримечательностями города и посетят интересный исторический объект – Форт №11 «Дёнхофф».

Сопровождающими и гидами на экскурсионных маршрутах станут участники проекта «Народный экскурсовод». Это активные горожане в возрасте 50+ которые разрабатывают свои авторские маршруты прогулок и поездок и серьезно интересуются историей края.

Результатом проекта, который завершится к середине 2017 года, станет путеводитель с маршрутами для пожилых людей, методические наработки и рекомендации по полученному опыту, которые можно будет внедрить в других регионах России.

При реализации проекта используются средства государственной поддержки, выделенные в качестве гранта РООИ «Здоровье человека» в соответствии c распоряжением Президента Российской Федерации №68-рп от 05.04.2016 и на основании конкурса, проведенного Общероссийской общественной организацией «Союз пенсионеров России».
